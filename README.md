# Texto a Voz Studio

Aplicación de escritorio para convertir texto en voz, ajustar voces y efectos, exportar audio WAV y conectar la aplicación mediante MCP.

<p align="center"><img src="assets/logo.png" alt="Texto a Voz Studio" width="600"></p>

## Descargas

Los instaladores se publican en [Releases](https://github.com/alonsonavastack/textoavoz-studio/releases).

- **Windows:** descarga el instalador `.exe` de la versión publicada.
- **macOS:** descarga el `.dmg` correspondiente a la arquitectura de tu Mac y arrastra la aplicación a Aplicaciones.

La primera versión pública está en preparación. Si Releases está vacío, todavía no hay un instalador publicado.

## Uso

1. Abre la aplicación.
2. Escribe el texto y selecciona una voz.
3. Ajusta los controles, reproduce y exporta el audio.

Las voces de Edge-TTS requieren conexión a internet. Consulta las notas de cada versión para conocer sus funciones y requisitos.

## Soporte

Reporta problemas en [Issues](https://github.com/alonsonavastack/textoavoz-studio/issues), indicando sistema operativo, versión de la aplicación y pasos para reproducir el error. No adjuntes contraseñas ni información privada.

Este repositorio contiene únicamente información pública, recursos gráficos e instaladores. El código fuente se mantiene en un repositorio privado independiente.
