# Texto a Voz Studio

<p align="center"><img src="assets/logo.png" alt="Texto a Voz Studio" width="600"></p>

Aplicación de escritorio para convertir texto en voz, ajustar voces y efectos, exportar audio WAV y conectarla con Claude Code.

## ⬇️ Descargar

**[Descargar la última versión](https://github.com/alonsonavastack/textoavoz-studio/releases/latest)**

| Tu equipo | Archivo |
|---|---|
| Windows (recomendado) | `Instalador_TextoAVoz_vX.Y.Z.exe` |
| Windows sin instalar | `TextoAVoz-Windows-Portable.zip` |
| Mac con chip Apple (M1 o posterior) | `TextoAVoz-macOS-arm64.dmg` |
| Mac con procesador Intel | `TextoAVoz-macOS-x86_64.dmg` |

¿No sabes cuál es tu Mac? Menú Apple, **Acerca de este Mac**: si dice «Chip», es Apple; si dice «Procesador», es Intel.

## 🛠️ Instalar

Los instaladores no están firmados ni notarizados, así que el sistema puede mostrar una advertencia la primera vez.

**Windows**
1. Abre el instalador.
2. Si aparece SmartScreen, pulsa **Más información** y luego **Ejecutar de todos modos**.

**macOS**
1. Abre el `.dmg` y arrastra **TextoAVoz** a **Aplicaciones**.
2. Abre la app. Si macOS la bloquea, ve a **Ajustes del Sistema → Privacidad y seguridad** y pulsa **Abrir de todos modos**.

## ▶️ Usar

1. Escribe el texto.
2. Elige una voz.
3. Ajusta velocidad, volumen, tono y efectos (robot, eco, reverb, distorsión, chorus y teléfono).
4. Pulsa **Reproducir**.
5. Para guardar el audio, escribe un nombre y pulsa **Guardar WAV**.

Puedes guardar tus ajustes como una configuración con nombre y cargarlos cuando quieras.

Las voces necesitan conexión a internet.

## 🔌 Conectar con Claude Code

1. Pulsa **Conectar con Claude Code** y luego **Conectar automáticamente**.
2. El botón se pone en 🟢 verde cuando está conectado, y en 🔴 rojo cuando no.
3. Abre una sesión nueva de Claude Code y pídele, por ejemplo: «genera la voz con mi configuración actual».

Para usar tu configuración actual, la app debe estar abierta.

## 🔄 Actualizar

Pulsa **Actualizaciones** dentro de la app. Si hay una versión nueva, pulsa **Actualizar ahora**: se descarga, se instala y la app se vuelve a abrir sola.

La versión portable de Windows se actualiza descargando el archivo nuevo.

## 💬 Soporte

Reporta problemas en [Issues](https://github.com/alonsonavastack/textoavoz-studio/issues) indicando tu sistema operativo, la versión de la app y los pasos para reproducir el error. No incluyas contraseñas ni información privada.
